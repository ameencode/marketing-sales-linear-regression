## 🔍 Project Overview

This project applies **Simple Linear Regression (OLS)** to a marketing spend dataset to answer a critical business question:

> *Which advertising channel — TV, Radio, or Social Media — has the strongest and most statistically significant impact on Sales, and how should the marketing budget be allocated to maximise ROI?*

The analysis is implemented entirely from first principles using NumPy and validated with SciPy. It covers the complete data science pipeline: data loading, cleaning, exploratory data analysis, model building, assumption testing, result interpretation, and a business-facing recommendation.

## 🧪 Methodology

### 1. Data Cleaning
Missing values were identified across all four columns (TV: 10, Radio: 4, Social Media: 6, Sales: 6). Since missing rows represent only **0.57%** of the dataset, listwise deletion was applied without introducing meaningful bias.

### 2. Exploratory Data Analysis (EDA)
- **Histograms** to examine the distribution shape of each variable
- **Scatter plots** of each marketing channel against Sales, with best-fit lines and Pearson r annotations
- **Correlation heatmap** to quantify linear relationships

### 3. Variable Selection
Pearson correlation coefficients between each channel and Sales:

| Channel | Pearson r | Interpretation |
|---|---|---|
| **TV** | **0.9995** | Near-perfect positive linear relationship |
| Radio | 0.8686 | Strong positive relationship |
| Social Media | 0.5274 | Moderate positive relationship |

**TV** was selected as the independent variable due to its overwhelmingly strong correlation with Sales.

### 4. OLS Regression — Closed-Form Solution

The model estimates coefficients using the standard OLS formulae:

```
β₁ = Σ[(xᵢ - x̄)(yᵢ - ȳ)] / Σ[(xᵢ - x̄)²]
β₀ = ȳ - β₁ · x̄
```

No external regression libraries (e.g. statsmodels) are required — the implementation uses only **NumPy** and **SciPy**, demonstrating a ground-up understanding of the algorithm.

### 5. Assumption Testing

| Assumption | Method | Test Used |
|---|---|---|
| **Linearity** | Residuals vs Fitted plot | Visual inspection |
| **Normality** | Q-Q plot + Residual histogram | Shapiro-Wilk test |
| **Homoscedasticity** | Scale-Location plot | Breusch-Pagan test (manual) |

## ✅ Regression Assumptions

All three core OLS assumptions were validated and passed:

### 1. Linearity
The Residuals vs Fitted plot shows residuals scattered randomly around zero with no discernible curve or systematic pattern. The rolling mean (shown in orange) remains flat — confirming that the linear specification is appropriate.

### 2. Normality of Residuals
- The **Normal Q-Q plot** shows data points closely following the reference line across the full quantile range
- The **residual histogram** closely matches the overlaid Normal PDF
- **Shapiro-Wilk test**: W = 0.9998, **p = 0.9136** → fail to reject H₀ → residuals are normally distributed ✅

### 3. Homoscedasticity (Constant Variance)
- The **Scale-Location plot** shows a flat, horizontal band of points — no funnel shape
- **Breusch-Pagan test**: F = 0.000059, **p = 0.9939** → fail to reject H₀ → error variance is constant ✅

| Assumption | Status | Evidence |
|---|---|---|
| Linearity | ✅ Passed | Residuals vs Fitted — no pattern |
| Normality | ✅ Passed | Shapiro-Wilk p = 0.914 |
| Homoscedasticity | ✅ Passed | Breusch-Pagan p = 0.994 |

## 💼 Business Recommendation

Based on the statistical analysis, the following is recommended for marketing budget allocation:

**Primary Channel — TV (Highest Priority)**
TV advertising is the dominant driver of Sales Revenue, accounting for 99.90% of its variation. For every additional $1,000 invested in TV spend, Sales increase by approximately $3,562, yielding a stable Return on Ad Spend of 3.56×. This relationship is consistent across all budget levels and is supported by a highly significant coefficient (t = 2125, p < 0.0001) with an extremely narrow 95% confidence interval [3.5582, 3.5648], indicating near-zero estimation uncertainty.

**Secondary Channel — Radio (Complementary)**
Radio demonstrates a strong positive relationship with Sales (r = 0.87) and should be retained as a complementary reach-extension channel. However, its high correlation with TV (r = 0.87) suggests some multicollinearity in a joint model, meaning its independent contribution warrants further analysis via multiple regression.

**Tertiary Channel — Social Media (Review Separately)**
Social Media shows the weakest linear relationship with Sales (r = 0.527). This does not necessarily imply low value — Social Media ROI often manifests through brand awareness, engagement, and long-term customer lifetime value that a short-term Sales regression will not capture. A dedicated analysis using engagement metrics or a lagged sales model is recommended.

**Suggested Allocation**

| Channel | Recommended Budget Share | Rationale |
|---|---|---|
| TV | 65–70% | Highest and most consistent ROI |
| Radio | 20–25% | Complementary reach; moderate ROI |
| Social Media | 10–15% | Engagement value; further evaluation needed |

> ⚠️ **Caveat:** This is a univariate model. A multiple regression including all three channels simultaneously would provide more precise allocation guidance by controlling for inter-channel correlations.

## ⚠️ Limitations & Future Work

### Current Limitations

- **Univariate model:** Only TV is used as a predictor. The model does not account for the joint effect of Radio and Social Media or their interactions.
- **Multicollinearity ignored:** TV and Radio are highly correlated (r = 0.87). In a multiple regression, this would require VIF analysis and potentially regularisation.
- **No temporal dimension:** The dataset does not include a time index. Advertising effects often have a lagged impact on sales (carryover effect / Adstock) that is not modelled here.
- **Assumed linearity:** The model imposes a linear functional form. Diminishing returns at high budget levels may warrant a log or polynomial specification.
- **No train/test split:** The model is fit and evaluated on the same data. A holdout set or cross-validation would provide more honest out-of-sample performance estimates.

### Suggested Extensions

- [ ] **Multiple Linear Regression** — include all three channels simultaneously
- [ ] **Polynomial Regression** — test for diminishing returns at high TV spend
- [ ] **Regularisation** — apply Ridge or Lasso if multicollinearity is confirmed
- [ ] **Adstock Modelling** — incorporate lagged advertising effects across time
- [ ] **Interaction Terms** — explore whether TV × Radio synergies exist
- [ ] **Segmentation Analysis** — run separate models by season, region, or product line
- [ ] **Statsmodels integration** — add an OLS summary table via `statsmodels.api.OLS` for academic reporting
